# Software Design Patterns in TypeScript

A comprehensive collection of Software Design Patterns implemented in **TypeScript**. This repository serves as a reference guide covering the problem statements, architectural tradeoffs, and modern implementations for Gang of Four (GoF) patterns.

---

## 📂 Repository Structure

Each pattern is organized inside its respective category folder containing:
* `README.md`: Problem breakdown, before/after comparison, and use cases.
* `index.ts`: Clean, fully-typed TypeScript implementation.
